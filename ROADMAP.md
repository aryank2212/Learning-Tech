# Roadmap

What's planned. Nothing here is a promise: this is a volunteer project, and the order follows what people ask for. **Want something moved up or added? [Open an issue.](https://github.com/aryank2212/Learning-Tech/issues/new/choose)**

## Next
- Small computer-vision and text projects for the PyTorch and TensorFlow guides, using free datasets
- Worked solutions and hints for the practice tasks (Level 1 first).
- More quiz questions per subject (aim: ten each).
- A "projects" page: bigger, portfolio-style builds that combine several subjects.
- Printable one-page cheat sheets for each language.

## Planned subjects
- **JAX and Flax** as a fifth framework guide
- **TypeScript** and **Assembly (x86-64 and RISC-V)** as languages
- **Databases in depth:** storage engines, query planning, transactions
- **Cloud and DevOps:** containers, Kubernetes, infrastructure as code, observability
- **Computer graphics and game development**
- **Embedded systems and robotics**
- **Natural language processing** and **computer vision** as their own tracks
- **MLOps:** versioning, deployment and monitoring of models
- **Human–computer interaction and UX**
- **Formal methods:** model checking and proof assistants

## Ideas under consideration
- Translations of the main guides
- Short video walkthroughs linked from each syllabus
- A study-group guide for running a reading circle or a weekly practice night
- A community "show your project" page

## Maintenance
- Weekly automatic link check (see `.github/workflows/checks.yml`)
- Review of versions and install commands every few months, since tools change
- Replace any resource that disappears or stops being the best option

## How decisions are made
Requests with a clear learning goal and a good free resource are easiest to add. If you're willing to write a first draft, say so in the issue; that moves things faster.
