# AI

Machine learning, LLM agents and how to do research.

- **[ML Libraries in Other Languages](frameworks/ml-libraries-other-languages/README.md)** — Machine-learning libraries beyond Python (Rust, C and C++, Java, Go, JavaScript, R, Julia and C#), and how to run one trained model from any of them
- **[Agentic AI & Orchestration](agents/agentic-ai/README.md)** — Building AI systems that plan, use tools, remember things and finish multi-step work
- **[Research](../research/README.md)** — Research is how a field moves forward
