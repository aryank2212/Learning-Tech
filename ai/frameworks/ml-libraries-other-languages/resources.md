# ML libraries in other languages: resources

## The bridge
- ⭐🆓 [ONNX](https://onnx.ai/): the model format
- ⭐🆓 [ONNX Runtime](https://onnxruntime.ai/): run models from many languages
- 🆓 [sklearn-onnx](https://onnx.ai/sklearn-onnx/): export scikit-learn pipelines
- 🆓 [PyTorch ONNX export](https://pytorch.org/docs/stable/onnx.html): the export documentation
- 🆓 [OpenVINO](https://docs.openvino.ai/) and [TensorRT](https://developer.nvidia.com/tensorrt): optimised inference on Intel and NVIDIA hardware
- 🆓 [Apache TVM](https://tvm.apache.org/): a compiler for running models on many devices

## Rust
- [Are We Learning Yet?](https://www.arewelearningyet.com/): a directory of Rust ML crates
- [Burn](https://burn.dev/) · [Candle](https://github.com/huggingface/candle) · [linfa](https://github.com/rust-ml/linfa) · [ndarray](https://github.com/rust-ndarray/ndarray) · [Polars](https://pola.rs/)
- [tch-rs](https://github.com/LaurentMazare/tch-rs) · [ort](https://ort.pyke.io/) · [tract](https://github.com/sonos/tract)
