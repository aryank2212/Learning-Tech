# PyTorch resources

## Start here
- ⭐🆓 [Official PyTorch tutorials](https://pytorch.org/tutorials/): begin with "Learn the Basics"
- ⭐🆓 [PyTorch documentation](https://pytorch.org/docs/stable/index.html): the reference; read the notes on autograd and CUDA semantics
- 🆓 [Learn PyTorch for Deep Learning](https://www.learnpytorch.io/): a free, long, code-first course
- 🆓 [Dive into Deep Learning](https://d2l.ai/): free, with PyTorch code throughout
- 🆓 [fast.ai Practical Deep Learning](https://course.fast.ai/) and [Karpathy's Zero to Hero](https://karpathy.ai/zero-to-hero.html): build from the ground up
- 🆓 [PyTorch performance tuning guide](https://pytorch.org/tutorials/recipes/recipes/tuning_guide.html)

## Libraries around PyTorch
- [torchvision](https://pytorch.org/vision/stable/index.html): datasets, transforms and pretrained vision models
- [PyTorch Lightning](https://lightning.ai/docs/pytorch/stable/): less boilerplate for training loops
- [TorchMetrics](https://lightning.ai/docs/torchmetrics/stable/): metrics that work across devices
- [Hugging Face Transformers](https://huggingface.co/docs/transformers/) and [timm](https://huggingface.co/docs/timm/): pretrained models
- [ONNX](https://onnx.ai/) and [ExecuTorch](https://pytorch.org/executorch/): export and edge deployment (see [ML libraries in other languages](../ml-libraries-other-languages/README.md))
- [TensorBoard](https://www.tensorflow.org/tensorboard): training dashboards that work with PyTorch too
