# scikit-learn resources

## Start here
- ⭐🆓 [scikit-learn user guide](https://scikit-learn.org/stable/user_guide.html): clear, complete, with maths
- ⭐🆓 [scikit-learn MOOC (Inria)](https://inria.github.io/scikit-learn-mooc/): a free course by the maintainers
- 🆓 [Examples gallery](https://scikit-learn.org/stable/auto_examples/index.html): runnable examples for every module
- 🆓 [Choosing the right estimator](https://scikit-learn.org/stable/machine_learning_map.html): a flowchart for picking a model
- 🆓 [Common pitfalls and recommended practices](https://scikit-learn.org/stable/common_pitfalls.html): short, and worth reading twice
- 🆓 [Kaggle Learn: Intro to Machine Learning](https://www.kaggle.com/learn): small notebook lessons

## Books
| | Book | Notes |
|---|---|---|
| ⭐💲 | *Hands-On Machine Learning with Scikit-Learn, Keras and TensorFlow* — Aurélien Géron | The most popular practical book |
| 💲 | *Introduction to Machine Learning with Python* — Müller & Guido | Short and focused on scikit-learn |
| 🆓 | *An Introduction to Statistical Learning* — James et al. | [Free](https://www.statlearning.com/); the theory behind the methods |
| 💲 | *Python Machine Learning* — Sebastian Raschka | Covers scikit-learn and PyTorch |

## Companion libraries
- [XGBoost](https://xgboost.readthedocs.io/), [LightGBM](https://lightgbm.readthedocs.io/) and [CatBoost](https://catboost.ai/): fast gradient boosting
- [imbalanced-learn](https://imbalanced-learn.org/stable/): resampling for skewed classes
- [SHAP](https://shap.readthedocs.io/en/latest/): explain individual predictions
- [Optuna](https://optuna.org/): smarter hyperparameter search
- [skops](https://skops.readthedocs.io/en/stable/): safer sharing of scikit-learn models
- [sklearn-onnx](https://onnx.ai/sklearn-onnx/): export pipelines to ONNX (see [ML libraries in other languages](../ml-libraries-other-languages/README.md))

## Practice and datasets
- [Kaggle competitions and datasets](https://www.kaggle.com/): start with the "Getting Started" competitions
- [OpenML](https://www.openml.org/): thousands of datasets, loadable with `fetch_openml`
- [UCI Machine Learning Repository](https://archive.ics.uci.edu/)
