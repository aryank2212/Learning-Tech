# TensorFlow and Keras resources

## Start here
- ⭐🆓 [TensorFlow tutorials](https://www.tensorflow.org/tutorials): begin with "Quickstart for beginners"
- ⭐🆓 [Keras guides](https://keras.io/guides/): clear, short and current
- 🆓 [Keras code examples](https://keras.io/examples/): vision, language, generative models, and more
- 🆓 [TensorFlow guide](https://www.tensorflow.org/guide): tensors, `tf.function`, `tf.data`, distributed training
- 🆓 [Google Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course): uses Keras

## Books
| | Book | Notes |
|---|---|---|
| ⭐💲 | *Deep Learning with Python* — François Chollet | By the author of Keras |
| 💲 | *Hands-On Machine Learning with Scikit-Learn, Keras and TensorFlow* — Aurélien Géron | Classical ML and deep learning together |
| 🆓 | [Dive into Deep Learning](https://d2l.ai/) | Free; has TensorFlow code in addition to PyTorch |

## Deployment tools
- [TensorFlow Serving](https://www.tensorflow.org/tfx/guide/serving): serve models over REST and gRPC
- [LiteRT](https://ai.google.dev/edge/litert) (formerly TensorFlow Lite): mobile and microcontrollers
- [TensorFlow.js](https://www.tensorflow.org/js): run models in the browser or Node
- [TensorBoard](https://www.tensorflow.org/tensorboard): training dashboards and profiling
- [KerasHub](https://keras.io/keras_hub/): pretrained models for Keras
- [OpenXLA](https://openxla.org/xla): the compiler behind `jit_compile`

## Papers
- Abadi et al., *TensorFlow: A System for Large-Scale Machine Learning* (OSDI 2016)
- Chollet, *Keras* and the Keras 3 announcement on [keras.io](https://keras.io/)
