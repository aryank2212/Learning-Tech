# Blockchain resources

## Primary sources (read these first)
- ⭐🆓 [Bitcoin whitepaper (2008)](https://bitcoin.org/bitcoin.pdf)
- ⭐🆓 [Ethereum whitepaper](https://ethereum.org/en/whitepaper/)
- 🆓 The Ethereum Yellow Paper (Gavin Wood) — the formal specification; search the title

## Books
- 🆓 [Bitcoin and Cryptocurrency Technologies](https://bitcoinbook.cs.princeton.edu/) — Narayanan, Bonneau, Felten, Miller, Goldfeder (free draft)
- 💲 *Mastering Bitcoin* — Andreas Antonopoulos
- 💲 *Mastering Ethereum* — Antonopoulos & Wood
- 💲 *Programming Bitcoin* — Jimmy Song

## Learning material
- ⭐🆓 [Ethereum developer docs](https://ethereum.org/en/developers/docs/)
- ⭐🆓 [Solidity documentation](https://docs.soliditylang.org/)
- 🆓 [Foundry Book](https://book.getfoundry.sh/)
- 🆓 [Hardhat documentation](https://hardhat.org/docs)
- 🆓 [OpenZeppelin Contracts](https://docs.openzeppelin.com/) — audited, standard contract libraries
- 🆓 [CryptoZombies](https://cryptozombies.io/) — interactive Solidity course
- 🆓 [Cyfrin Updraft](https://updraft.cyfrin.io/) — free Solidity and security course
- 🆓 Stanford CS251 (blockchain) lecture materials — search the course name

## Security
- ⭐🆓 [Damn Vulnerable DeFi](https://www.damnvulnerabledefi.xyz/) — practice finding real bug classes
- 🆓 [SWC Registry](https://swcregistry.io/) — catalogue of smart-contract weaknesses
- 🆓 [Consensys smart contract best practices](https://consensys.github.io/smart-contract-best-practices/)
- 🆓 [Rekt News](https://rekt.news/) — post-incident write-ups
- 🆓 [CryptoHack](https://cryptohack.org/) — cryptography challenges, with blockchain categories

## Tools
- [Foundry](https://getfoundry.sh/), [Hardhat](https://hardhat.org/)
- [Remix IDE](https://remix.ethereum.org/) — browser-based Solidity editor
- [Sepolia testnet explorer](https://sepolia.etherscan.io/) — read-only; you don't need a wallet to read
- [viem](https://viem.sh/) and [ethers.js](https://docs.ethers.org/)
- [Circom on GitHub](https://github.com/iden3/circom) — zero-knowledge circuits
