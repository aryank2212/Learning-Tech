# Practice: Data Science

Work through the levels in order. Spend at least 30 minutes on a task before looking anything up. At the end, a short quiz checks the key ideas, and each answer is hidden until you click it.

How to check yourself: write tests for each task, or compare your output with a known answer. For maths and theory, check by hand and then with code.

## Level 1 — Easy (warm-up)

- [ ] Load a CSV and print summary statistics.
- [ ] Plot a histogram of one column.
- [ ] Count the missing values in each column.

## Level 2 — Medium (apply it)

- [ ] Clean a dataset: handle missing values and duplicates, and log every change.
- [ ] Train a logistic regression baseline and report its accuracy.
- [ ] Build a three-chart dashboard with a short written summary.

## Level 3 — Hard (build and explain)

- [ ] Take a Kaggle dataset from question to written report.
- [ ] Calculate the sample size for an A/B test, then analyse the result.

## Quick quiz

Answer each question out loud or on paper first, then open the answer.

1. What is a train/test split for?

   <details><summary>Show answer</summary>

   To estimate how a model performs on data it hasn't seen.

   </details>

2. What is data leakage?

   <details><summary>Show answer</summary>

   Information from the test set or the future influences training, so reported performance is better than real performance.

   </details>

3. What's the difference between precision and recall?

   <details><summary>Show answer</summary>

   Precision: of the items predicted positive, how many are truly positive. Recall: of the truly positive items, how many were found.

   </details>

4. Why is accuracy misleading with imbalanced classes?

   <details><summary>Show answer</summary>

   A model that always predicts the majority class can score high accuracy without finding any of the minority class.

   </details>
