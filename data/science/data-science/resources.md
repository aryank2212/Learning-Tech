# Data science resources

## Books
| | Book | Notes |
|---|---|---|
| ⭐💲 | *Python for Data Analysis* — Wes McKinney | Written by the creator of pandas |
| ⭐🆓 | *R for Data Science* (2nd ed) — Wickham, Çetinkaya-Rundel, Grolemund | [Free online](https://r4ds.hadley.nz/) |
| 💲 | *Practical Statistics for Data Scientists* — Bruce, Bruce, Gedeck | Statistics for working analysts |
| 💲 | *Storytelling with Data* — Cole Nussbaumer Knaflic | Charts that communicate |
| 💲 | *Designing Machine Learning Systems* — Chip Huyen | Production ML |
| 💲 | *Trustworthy Online Controlled Experiments* — Kohavi, Tang, Xu | A/B testing at scale |
| 💲 | *Data Science for Business* — Provost & Fawcett | Business framing |
| 💲 | *The Data Science Handbook* — Field Cady | Broad overview |

## Courses
- ⭐🆓 [Kaggle Learn](https://www.kaggle.com/learn) — short notebook courses
- 🆓 [Data Carpentry lessons](https://datacarpentry.org/lessons/) — hands-on, free
- 🆓 [Google Data Analytics Certificate](https://grow.google/certificates/data-analytics/) — structured path, paid certificate
- 🆓 [StatQuest with Josh Starmer](https://www.youtube.com/@statquest) — statistics and ML explained clearly
