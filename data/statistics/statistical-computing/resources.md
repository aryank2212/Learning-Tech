# Statistical computing resources

## Books
| | Book | Notes |
|---|---|---|
| ⭐🆓 | *OpenIntro Statistics* | [Free](https://www.openintro.org/book/os/) — friendly, applied |
| ⭐💲 | *All of Statistics* — Larry Wasserman | Compact and broad |
| 💲 | *Statistical Inference* — Casella & Berger | The standard theory text |
| ⭐💲 | *Statistical Rethinking* (2nd ed) — Richard McElreath | Bayesian thinking; code in R and Python |
| 🆓 | *Bayesian Data Analysis* — Gelman et al. | Free PDF from the authors' site |
| 🆓 | *Modern Statistics with R* — Måns Thulin | [Free](https://www.modernstatisticswithr.com/) |
| 💲 | *Computational Statistics* — Givens & Hoeting | Algorithms behind the methods |
| 🆓 | *R for Data Science* | [Free](https://r4ds.hadley.nz/) |
