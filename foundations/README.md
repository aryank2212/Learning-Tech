# Foundations

Maths, theory, hardware and algorithms: the base everything else stands on.

- **[Maths](mathematics/maths/README.md)** — The mathematics that computer science and engineering rely on, in two parts
- **[Theory of Computation](theory/theory-of-computation/README.md)** — What computers can do, what they can't do, and how much effort the things they can do really take
- **[Digital Electronics](hardware/digital-electronics/README.md)** — How logic is built from transistors and gates, and how gates become memory, adders and CPUs
- **[Computer Architecture](hardware/computer-architecture/README.md)** — How a processor is organised so that it runs instructions quickly: instruction set design, pipelining, the memory hierarchy, branch prediction, parallel execution inside
- **[DSA & Advanced DSA](algorithms/dsa/README.md)** — Data structures and algorithms: how to store data so operations are fast, and how to solve problems efficiently

Each subject has an install guide, syllabus, resources, a practice file and my take. Tutorials for all subjects are in [tutorial.md](../tutorial.md).
