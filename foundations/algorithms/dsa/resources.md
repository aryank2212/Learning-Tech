# DSA resources

## Books
| | Book | Notes |
|---|---|---|
| ⭐💲 | *Introduction to Algorithms* (CLRS) — Cormen, Leiserson, Rivest, Stein | The standard reference |
| 💲 | *The Algorithm Design Manual* — Steven Skiena | Problem-first, very practical |
| 💲 | *Algorithms* — Sedgewick & Wayne | Clear, with Java code |
| 💲 | *Algorithms Illuminated* (Parts 1–4) — Tim Roughgarden | Short and clear, good for theory |
| 💲 | *Competitive Programming 4* — Halim, Halim, Effendy | For contests |
| 🆓 | *Competitive Programmer's Handbook* — Antti Laaksonen | Free PDF from the CSES site |
| 💲 | *Grokking Algorithms* — Aditya Bhargava | Gentle introduction with pictures |
