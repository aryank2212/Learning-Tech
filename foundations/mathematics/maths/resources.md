# Maths resources

## Books
| | Book | Notes |
|---|---|---|
| ⭐🆓 | *Mathematics for Machine Learning* — Deisenroth, Faisal, Ong | [Free PDF](https://mml-book.github.io/) |
| ⭐🆓 | *Book of Proof* — Richard Hammack | [Free PDF](https://www.people.vcu.edu/~rhammack/BookOfProof/); the best start for proofs |
| 💲 | *Discrete Mathematics and Its Applications* — Kenneth Rosen | Standard university text |
| 💲 | *Concrete Mathematics* — Graham, Knuth, Patashnik | Counting, sums, recurrences; hard but excellent |
| 🆓 | *Mathematics for Computer Science* — Lehman, Leighton, Meyer | Free from [MIT 6.042J](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-fall-2010/) |
| 💲 | *Introduction to Graph Theory* — Douglas West | Graph theory reference |
| 💲 | *Linear Algebra Done Right* — Sheldon Axler | Proof-based linear algebra |
| 💲 | *Introduction to Linear Algebra* — Gilbert Strang | Applied linear algebra |
| 💲 | *Calculus* — Michael Spivak | Rigorous calculus |
