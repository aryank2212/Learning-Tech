# Compiler design resources

## Books
| | Book | Notes |
|---|---|---|
| ⭐🆓 | *Crafting Interpreters* — Robert Nystrom | [Free online](https://craftinginterpreters.com/); the friendliest start |
| 💲 | *Compilers: Principles, Techniques, and Tools* ("Dragon Book") — Aho, Lam, Sethi, Ullman | Classic reference |
| 💲 | *Engineering a Compiler* — Cooper & Torczon | Practical and modern |
| 💲 | *Modern Compiler Implementation* — Andrew Appel | Available in C, Java and ML editions |
| 💲 | *Advanced Compiler Design and Implementation* — Steven Muchnick | Deep optimisation |
| 💲 | *Programming Language Pragmatics* — Michael Scott | Languages and implementation together |
| 🆓 | *Static Single Assignment Book* — Rastello & Bouchez Tichadou (free; search the title) | Free SSA reference |

## Tutorials and courses
- ⭐🆓 [LLVM Kaleidoscope tutorial](https://llvm.org/docs/tutorial/)
- 🆓 [LLVM Language Reference](https://llvm.org/docs/LangRef.html)
- 🆓 [Writing a C Compiler (Nora Sandler)](https://norasandler.com/) — step-by-step C compiler in stages
- 🆓 Jack Crenshaw's *Let's Build a Compiler* — search the title; a classic
- 🆓 Stanford CS143 and Cornell CS 4120 compiler course materials — search the course names
- 🆓 [Rust compiler developer guide](https://rustc-dev-guide.rust-lang.org/) — how a production compiler is organised

## Tools
- [Compiler Explorer (godbolt.org)](https://godbolt.org/) — see the assembly for any snippet
- [LLVM](https://llvm.org/), [ANTLR](https://www.antlr.org/), [Tree-sitter](https://tree-sitter.github.io/), [Graphviz](https://graphviz.org/)

## Papers
- Milner, *A Theory of Type Polymorphism in Programming* (1978) — the basis of Hindley–Milner inference
- Leroy, *Formal Verification of a Realistic Compiler* (CACM 2009) — CompCert
- Lattner et al., *MLIR: A Compiler Infrastructure for the End of Moore's Law* (arXiv:2002.11054)
