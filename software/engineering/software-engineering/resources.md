# Software engineering resources

## Books
| | Book | Notes |
|---|---|---|
| ⭐🆓 | *Software Engineering at Google* — Winters, Manshreck, Wright | [Free online](https://abseil.io/resources/swe-book); how a large team works |
| ⭐💲 | *The Pragmatic Programmer* — Hunt & Thomas | Practical habits, short chapters |
| 💲 | *A Philosophy of Software Design* — John Ousterhout | Complexity and module design |
| 💲 | *Refactoring* (2nd ed) — Martin Fowler | Small, safe transformations |
| 💲 | *Working Effectively with Legacy Code* — Michael Feathers | Changing code that has no tests |
| 💲 | *Test-Driven Development: By Example* — Kent Beck | The TDD cycle, step by step |
| 💲 | *Clean Code* — Robert C. Martin | Widely read; read it critically |
| 💲 | *Release It!* (2nd ed) — Michael Nygard | Production failures and how to design against them |
| 💲 | *Accelerate* — Forsgren, Humble, Kim | What the research says about high-performing teams |
| 💲 | *The Mythical Man-Month* — Fred Brooks | Classic essays on teams and complexity |
| 🆓 | *Site Reliability Engineering* — Google | [Free online](https://sre.google/books/) (also in [system architecture](../../../systems/architecture/system-architecture/resources.md)) |

## Courses and free guides
- ⭐🆓 [The Missing Semester of Your CS Education (MIT)](https://missing.csail.mit.edu/) — the shell, git, debugging and tooling
- ⭐🆓 [Pro Git](https://git-scm.com/book) — the complete git book, free
- 🆓 MIT 6.031 Software Construction (OCW) — search the course number for the free lecture notes
- 🆓 [GitHub Skills](https://skills.github.com/) — short interactive courses on git, Actions and security
- 🆓 [Google engineering practices](https://google.github.io/eng-practices/) — code review and change guidelines

## Standards and conventions
- [The Twelve-Factor App](https://12factor.net/) — how to build deployable services
- [Semantic Versioning](https://semver.org/) — what version numbers mean
- [Conventional Commits](https://www.conventionalcommits.org/) — readable commit history
- [Keep a Changelog](https://keepachangelog.com/) — writing changelogs people read

## Tools
- [pre-commit](https://pre-commit.com/) — run checks before each commit
- [act](https://github.com/nektos/act) — run GitHub Actions locally
- [Hypothesis](https://hypothesis.readthedocs.io/) — property-based testing for Python
- [pytest](https://docs.pytest.org/) — Python testing
- [GitHub Actions documentation](https://docs.github.com/en/actions)
- [Terraform tutorials](https://developer.hashicorp.com/terraform/tutorials) — infrastructure as code

## Papers and essays

- Brooks, *No Silver Bullet: Essence and Accidents of Software Engineering* (1986)
- Lehman, *Programs, Life Cycles, and Laws of Software Evolution* (Proceedings of the IEEE, 1980)
