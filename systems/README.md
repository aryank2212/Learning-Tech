# Systems

Operating systems, networks, architecture and distributed computing.

- **[Operating Systems](kernels/operating-systems/README.md)** — How a computer manages processes, memory, files, devices and security
- **[Computer Networking](networks/computer-networking/README.md)** — How devices talk to each other: from electrical signals on a cable to a web page loading
- **[System Architecture](architecture/system-architecture/README.md)** — How computers, networks and large software systems work together, and how to design them
- **[Parallel & Distributed Computing](distributed/parallel-distributed-computing/README.md)** — Running work on many cores and many machines at once: shared-memory threads, message passing, GPUs, data-parallel frameworks, and the hard parts of distributed systems

Each subject has an install guide, syllabus, resources, a practice file and my take. Tutorials for all subjects are in [tutorial.md](../tutorial.md).
