# Operating systems resources

## Books
| | Book | Notes |
|---|---|---|
| ⭐🆓 | *Operating Systems: Three Easy Pieces* — Arpaci-Dusseau & Arpaci-Dusseau | [Free online](https://pages.cs.wisc.edu/~remzi/OSTEP/); the best place to start |
| 💲 | *Operating System Concepts* ("Dinosaur book") — Silberschatz, Galvin, Gagne | Classic textbook |
| 💲 | *Modern Operating Systems* — Tanenbaum & Bos | Broad coverage |
| 💲 | *Operating Systems: Principles and Practice* — Anderson & Dahlin | Good for projects |
| 💲 | *The Linux Programming Interface* — Michael Kerrisk | Systems programming reference |
| 💲 | *Linux Kernel Development* — Robert Love | Kernel basics |
| 💲 | *Understanding the Linux Kernel* — Bovet & Cesati | Deep kernel internals |

## Courses and hands-on labs
- ⭐🆓 [MIT 6.1810 Operating System Engineering (xv6 labs)](https://pdos.csail.mit.edu/6.1810/)
- ⭐🆓 [Writing an OS in Rust](https://os.phil-opp.com/)
- 🆓 [Linux From Scratch](https://www.linuxfromscratch.org/) — build a Linux system by hand
- 🆓 Stanford CS 140 (Pintos) and Berkeley CS 162 — search the course names for their project materials

## Tools
`strace`, `ltrace`, `perf`, `gdb` ([sourceware.org/gdb](https://sourceware.org/gdb/)), [Valgrind](https://valgrind.org/), [QEMU](https://www.qemu.org/).

## Classic papers
- Ritchie & Thompson, *The UNIX Time-Sharing System* (1974)
- McKusick et al., *A Fast File System for UNIX* (1984)
- Ghemawat et al., *The Google File System* (SOSP 2003)
- Klein et al., *seL4: Formal Verification of an Operating System Kernel* (SOSP 2009)
