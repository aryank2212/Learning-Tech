# Computer networking resources

## Books
| | Book | Notes |
|---|---|---|
| ⭐💲 | *Computer Networking: A Top-Down Approach* — Kurose & Ross | The most common university text |
| 🆓 | *Computer Networks: A Systems Approach* — Peterson & Davie | [Free online](https://book.systemsapproach.org/) |
| ⭐🆓 | *High Performance Browser Networking* — Ilya Grigorik | [Free online](https://hpbn.co/); TCP, TLS, HTTP |
| 💲 | *Computer Networks* — Tanenbaum & Wetherall | Thorough, classic |
| 💲 | *TCP/IP Illustrated, Vol. 1* — W. Richard Stevens | Protocol reference |
| 💲 | *UNIX Network Programming* — Stevens | Socket programming |
| 🆓 | [Beej's Guide to Network Programming](https://beej.us/guide/bgnet/) | Practical sockets tutorial |

## Courses and videos
- ⭐🆓 [Stanford CS144 — Introduction to Computer Networking](https://cs144.github.io/) (builds a TCP stack)
- 🆓 [Professor Messer](https://www.professormesser.com/) — Network+ and CCNA videos
- 🆓 [Cisco Networking Academy](https://www.netacad.com/)
- 🆓 [Cloudflare Learning Center](https://www.cloudflare.com/learning/) — short explainers on DNS, TLS, HTTP

## Standards (RFCs)
- ⭐ [RFC 791 — IPv4](https://www.rfc-editor.org/rfc/rfc791), [RFC 793 — TCP](https://www.rfc-editor.org/rfc/rfc793)
- [RFC 1034 — DNS concepts](https://www.rfc-editor.org/rfc/rfc1034)
- [RFC 9110 — HTTP semantics](https://www.rfc-editor.org/rfc/rfc9110)
- [RFC 9000 — QUIC](https://www.rfc-editor.org/rfc/rfc9000)
- Full index: [rfc-editor.org](https://www.rfc-editor.org/)

## Tools
- [Wireshark](https://www.wireshark.org/), `tcpdump`, `nmap` (only on networks you may test), `iperf3`, `mtr`, `dig`, `curl -v`
- [Mininet](http://mininet.org/), [GNS3](https://www.gns3.com/), Cisco Packet Tracer

## Papers
- Cardwell et al., *BBR: Congestion-Based Congestion Control* (ACM Queue, 2016)
- Langley et al., *The QUIC Transport Protocol: Design and Internet-Scale Deployment* (SIGCOMM 2017)
