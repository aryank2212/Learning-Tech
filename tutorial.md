# Tutorials

A curated set of free tutorials for every subject, in the order to read them. Each subject also has a [practice file](practice.md) and a syllabus. Tutorials change, so if a link breaks, [open an issue](https://github.com/aryank2212/Learning-Tech/issues) and we'll fix it.

Start with the first tutorial in your chosen subject. Work through it with a terminal open, not just reading.
