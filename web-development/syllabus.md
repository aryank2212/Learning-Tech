# Web development syllabus

Tick items in [progress/TRACKER.md](../progress/TRACKER.md).

## Phase 1 – HTML
- [ ] Document structure, `<head>`, metadata, `lang`
- [ ] Headings, paragraphs, lists, links, images
- [ ] Forms and inputs, labels, validation attributes
- [ ] Semantic elements: `header`, `nav`, `main`, `section`, `article`, `footer`
- [ ] Accessibility basics: alt text, labels, keyboard navigation

🛠️ **Project:** a personal résumé page in semantic HTML.

## Phase 2 – CSS
- [ ] Selectors, specificity, the cascade
- [ ] Box model, margin, padding, borders
- [ ] Typography and colour; CSS custom properties (variables)
- [ ] Flexbox (games: https://flexboxfroggy.com)
- [ ] Grid (game: https://cssgridgarden.com)
- [ ] Responsive design: media queries, `clamp()`, mobile-first
- [ ] Transitions and animations

🛠️ **Project:** make the résumé responsive with a dark mode toggle.

## Phase 3 – JavaScript
- [ ] Variables, types, functions, arrow functions
- [ ] Arrays and objects; array methods (`map`, `filter`, `reduce`)
- [ ] DOM: selecting, changing, events
- [ ] `fetch` and JSON
- [ ] Promises, `async`/`await`
- [ ] Modules (`import`/`export`), ES2015+ syntax
- [ ] Debugging with devtools breakpoints

🛠️ **Project:** a todo list with localStorage, no framework.

## Phase 4 – TypeScript
- [ ] Types, interfaces, union types, generics
- [ ] Typing functions, API responses, components
- [ ] `tsconfig.json` and strict mode

🛠️ **Project:** convert the todo list to TypeScript.

## Phase 5 – React and frameworks
- [ ] Components, props, JSX
- [ ] State: `useState`, derived state
- [ ] Effects: `useEffect`, cleanup, when not to use it
- [ ] Forms and controlled inputs
- [ ] Routing (React Router, or Next.js file routes)
- [ ] Data fetching, loading and error states
- [ ] State management: context, then Zustand or Redux Toolkit
- [ ] Styling: Tailwind CSS, or CSS modules

🛠️ **Project:** a movie-search app using a public API, with favourites saved locally.

## Phase 6 – Full-stack
- [ ] Node.js basics, npm scripts, environment variables
- [ ] Express or Fastify: routes, middleware, JSON APIs
- [ ] Databases: SQL with Postgres (see [SQL](../languages/sql/README.md)), or an ORM like Prisma or Drizzle
- [ ] Authentication: sessions or JWT; hashing passwords
- [ ] Validation with Zod
- [ ] Next.js full-stack: route handlers and server components

🛠️ **Project:** a notes app with login, a database and CRUD.

## Phase 7 – Quality and production
- [ ] Testing: Vitest or Jest for logic, Playwright for end-to-end
- [ ] Performance: Lighthouse audits, image optimisation, code splitting
- [ ] SEO basics: metadata, sitemap, semantic HTML
- [ ] Security: XSS, CSRF, CORS, secure cookies
- [ ] Deployment: Vercel, Netlify or Render
- [ ] CI with GitHub Actions: lint, test, deploy

🛠️ **Project:** deploy the notes app with a CI pipeline and a custom domain.

## Phase 8 – Specialisations (pick one or two)
- [ ] Animation and creative UI (GSAP, Framer Motion, Three.js)
- [ ] Real-time apps (WebSockets, Socket.IO)
- [ ] Mobile web and PWAs
- [ ] E-commerce or CMS (Shopify, Sanity, Strapi)
- [ ] Web3 / on-chain front ends (optional)
- [ ] Accessibility specialist (WCAG, screen-reader testing)
