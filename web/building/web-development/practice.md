# Practice: Web Development

Work through the levels in order. Spend at least 30 minutes on a task before looking anything up. At the end, a short quiz checks the key ideas, and each answer is hidden until you click it.

How to check yourself: write tests for each task, or compare your output with a known answer. For maths and theory, check by hand and then with code.

## Level 1 — Easy (warm-up)

- [ ] Build a two-column responsive page with CSS Grid.
- [ ] Build a form with labels and client-side validation.
- [ ] Fetch JSON from a public API and display it.

## Level 2 — Medium (apply it)

- [ ] Build a todo app that saves to localStorage.
- [ ] Build a React counter and list with `useState`.
- [ ] Write an Express route that validates its input.

## Level 3 — Hard (build and explain)

- [ ] Build a full-stack notes app with login and Postgres.
- [ ] Deploy the app with CI and run Lighthouse on it.

## Quick quiz

Answer each question out loud or on paper first, then open the answer.

1. What does `display: flex` do?

   <details><summary>Show answer</summary>

   It makes the element a flex container, laying out its children along a main axis.

   </details>

2. What does React's `useState` return?

   <details><summary>Show answer</summary>

   A pair: the current state value and a function that updates it.

   </details>

3. Why shouldn't you put secrets in frontend code?

   <details><summary>Show answer</summary>

   Everything sent to the browser can be read by users.

   </details>

4. How are `async`/`await` and promises related?

   <details><summary>Show answer</summary>

   `async`/`await` is syntax over promises. An `async` function returns a promise, and `await` pauses until it settles.

   </details>
